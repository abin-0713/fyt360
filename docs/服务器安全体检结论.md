## 四、建议动作（按风险从低到高，**均未执行**）

1. **宝塔 → 安全 → 开启「SSH 防爆破」**（连续失败自动封 IP）。作用域仅限 SSH 暴破源，不影响任何站点功能。
2. **宝塔 → 面板设置 → 授权域名**：填**实际访问面板所用的地址**。⚠️ 填错会把自己挡在面板外（此时可用 SSH 登录后删除 `/www/server/panel/data/domain.conf` 恢复），故建议本人操作。
3. 删除**多余放行**：`5432`、`8888`（当前无人使用；证据见上表）。
4. 若确认不使用：关闭 **FTP(20/21/39000-40000)** 与 **888(phpMyAdmin)** 的公网放行，改用宝塔面板内的文件管理与数据库管理。
5. **关闭 SSH 密码登录（仅密钥）** —— 最彻底，但必须按顺序做：
   ① 先生成密钥并写入 `authorized_keys` → ② 开新终端验证密钥可登录（**不要关闭当前会话**）→ ③ 才改 `PasswordAuthentication no` + `sshd -t` 校验 + `reload`（不是 restart）→ ④ 保留华为云控制台 VNC 作为兜底通道。
6. 云侧：华为云控制台 → 安全组，可进一步把 22/8889 限制为仅本人常用 IP（注意家用宽带 IP 变动会导致连不上，务必保留宝塔/VNC 通道）。
